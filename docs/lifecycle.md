# 设备生命周期管理

本次升级保留现有成员、测量和设备关联。添加管理入口不等于执行重置；真实健康数据的删除需要在页面查看影响范围后单独确认。

## 三层绑定

1. 新 ESP32 首次通过本机配网页设置 Wi-Fi/MQTT，联网后在 Eir 的「待添加」中核对设备 ID、IP 和固件，再填写名称、位置并绑定。
2. 在已绑定采集端上扫描、添加欧姆龙，按设备提示完成物理配对。新关联完成记录基线后才启用；当前有效旧记录不回填。
3. 将具体血压计的用户 1／2 关联到家庭成员。结束成员绑定不修改已有记录归属；后续没有对应绑定的测量进入待归属列表。

一个采集端可以管理多台血压计；单台血压计只能分配给一个采集端。迁移保留既有设备的采集范围，不自动重新建立基线。

## 删除、解绑和重置的区别

| 操作 | 本机影响 | Eir 历史 |
|---|---|---|
| 解绑 ESP32 | 在线停止采集、补传已缓存记录，清理采集关联和蓝牙绑定；保留网络配置 | 保留 |
| 直接删除 ESP32 | Eir 立即撤销关联；离线设备可能仍留有本地数据，不能称为已擦除 | 保留来源和健康历史 |
| 普通重置 ESP32 | 在线清理采集配置、缓存、进度、调试数据；保留网络配置和固件 | 保留 |
| 恢复出厂 | 清理上述数据并清除 Wi-Fi/MQTT，重启进入配网热点 | 保留；等待重新配网核实 |
| 解绑欧姆龙 | 只停止、补传并清理该血压计的绑定和进度 | 保留 |
| 清空健康数据 | 相关采集端在线、血压计可读取后，建立新基线并清理旧缓存 | 删除健康数据，保留成员和设备 |
| 完整重置 Eir | 撤销所有管理关联；离线 ESP32 的本地数据无法同步擦除 | 清空成员、健康数据、设备和关联 |

恢复出厂不会擦除固件本身。系统重置不删除血压计内存、固件库、服务连接配置、备份或已经导出的文件。备份／导出仍可能含历史健康信息，需自行保管。

蓝牙解绑必须定位实际配对身份，无法唯一定位时报告未完成清理，不允许用全局清空蓝牙绑定替代。远程重置只对在线且支持当前协议的固件开放；离线时可直接从 Eir 删除。

## 可靠性边界

- 服务实例、关联代次、数据代次和设备入网请求标识共同隔离旧消息。旧 retained 配置和迟到上报不能让已删除设备自动恢复绑定。
- 基线依据有效记录内容，而非单独依赖测量时间。设备时钟错误、时间回退或序号回绕不会作为丢弃新测量的唯一依据。
- 基线未建立时保持待启用，并提示唤醒血压计；不能将下一次正常测量静默当作基线。
- 页面显示耗时操作进度与失败原因。出厂重置进入等待重新配网不等于已经核实完成；离线删除不等于设备端擦除。
- 重复提交同一重置确认返回同一操作，不得再次清空新产生的数据。设备断电或服务重启后应恢复已有操作。

## 隔离验证

仅在 `eir-test-*` Compose 项目中运行破坏性回归，使用独立 PostgreSQL 卷、测试 Mosquitto 和非 8080 端口。脚本检查项目名称、MQTT 目标和卷名，不连接真实采集端。

`docs/acceptance.md` 记录实际运行结果；模拟 MQTT 设备测试证明服务端行为，不替代实际 ESP32 断电、恢复出厂、配对和蓝牙凭据清理验收。

运行服务端生命周期回归：

```sh
./scripts/lifecycle_integration.sh
```

默认使用 18082 端口；脚本自动创建和清理独立项目及卷。可通过 `EIR_TEST_PORT` 调整测试端口，通过 `EIR_TEST_KEEP=1` 保留失败环境以排查。使用已构建镜像时设置 `EIR_TEST_SKIP_BUILD=1 EIR_TEST_IMAGE=<测试镜像>`。旧版本兼容性回归仍使用 `./scripts/integration.sh`，它显式创建迁移前采集端测试夹具，不把新设备心跳当作绑定。

已有数据库升级前可执行迁移演练：

```sh
EIR_TEST_IMAGE=eir:lifecycle-final ./scripts/migration_integration.sh /绝对路径/database.dump
```

该脚本只向独立临时测试卷恢复备份，启动新版本并在数据库内比较升级前后的全部测量 ID、原始值和解析值，输出通过／失败及记录数量，不输出个人测量明细。完成后删除该临时测试项目及卷，保留输入备份和真实服务。


## 体脂秤扩展

阿福体脂秤按整台设备绑定一个成员（内部档位 0），不使用体重匹配成员。绑定需唤醒秤并验证通知服务；不进行欧姆龙注册写入。由于 D8 历史未验证，使用空历史基线，启用后接收实时测量。数据重置时秤只准备空基线，不要求休眠秤连接；血压计仍需读取基线。解绑只清理指定秤的周期和本地文件，保留其他秤及血压计。详见 [体脂秤说明](body-scale.md)。

准备尚未建立时，撤销应作为幂等空操作成功，释放服务端重试占用；不得清理其他操作拥有的准备状态。0.3.2 修正了此前空撤销失败并缓存回执、导致绑定失败后无法重试的问题，并允许仅针对这一旧失败回执重新执行安全撤销。
